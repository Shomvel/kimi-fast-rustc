# Protected private argument snapshots

The actual default reduces humantime duration parsing from **462,649,019** to **450,598,650** instructions, **2.604646%**, against accepted `148edfa`. All thirteen runtime instruction ratios have geometric mean **0.99799766** against that default and **1.12515050 × LLVM MIR0**. Text falls **163 B**, to **88,570 B**. The four captured compiles increase **0.144975%** in instructions, to **10,693,957,303**, **1.50330668 × LLVM**. This is an accepted runtime/text versus compiler-work tradeoff. The all-metrics 1.1 objective remains incomplete.

Private argument promotion can now replace an authenticated, sized `Frozen`/`Unique` reference with strictly observed entry snapshots of its read-only fields, even when other parameters participate in writes or direct calls. The exhaustive root-use walk permits only same-pointee casts, field addresses and loads; escapes, root writes, unknown operations, indirect calls and TLS reject the proof. Bounds, alignment and exact nonzero dereferenceable size are checked. Each promoted part still needs an unconditional entry load and strict observation before the first branch or unrelated effect. Caller observations of every original argument execute before the new loads. New snapshot parameters receive permission `None`. Thin pointers/shared references and x86-64 shared str/slice Pair values use the existing private ABI transaction; original admission budgets remain unchanged. `KFRC_PROTECTED_ARGUMENT_PROMOTION=0` restores the preceding path.
