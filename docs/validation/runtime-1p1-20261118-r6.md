# Single codegen unit for the standalone backend

The standalone backend now builds its release crates with one codegen unit. The standalone Cargo workspace does not inherit the root release profile. This change leaves optimization level, LTO, panic and stripping settings, lockfiles, benchmark crate flags, and the backend's generated code unchanged.

On the same Linux guest, the four original captured compiles retire **10,619,491,110** instructions (sum of per-crate medians), down **0.6902%** from the rebuilt accepted `2a79aff` backend. All twelve paired crate measurements improve for instructions, cycles, task-clock and peak RSS. The aggregate cycles reduction is **1.31–1.82%** across the three pairs. Wall improves in eleven of twelve pairs: one semver run is 3.80% slower, and the aggregate wall ratios are 0.99219, 1.00322 and 0.98395. User and system time vary. These are measurements of the released backend compiling the four libraries, not measurements of the time to build that backend.

Text passes **0/4**. The all-metrics objective remains incomplete. The [structured receipt](runtime-1p1-20261118-r6.json) contains all seven metrics, all individual LLVM thresholds, and the raw paired data. Only fresh measurements from the same guest enter the ratios above.

The candidate is exactly `2a79aff02b3705376c7d68669ad1069b7ea0dc12` plus the 429-byte manifest patch (`44c07420995b78289a41ce2b29727118d808c825d9c9933db3e5158399669f40`). Rust 1.94.1 / LLVM 21.1.8 on Linux x86-64. The initial run passed **1,455 workspace tests**, **30 backend tests** and all **18 original native stages**. The fresh guest reproduced the candidate backend and repeated the original eighteen native stages and all thirteen original-count checksum and object gates. Its verbose locked release build recorded 48 compiler invocations and confirmed one codegen unit for the optimized target crates with no new LTO, panic or strip flags. The separate preexisting `tests/p1-memory/run.sh` fixture was outside the gate and was not rerun.

The formal run used one discarded warmup and three interleaved repeats across five configurations with the original four commands, LLVM callers and shared LLVM MIR0 sysroot. The archive audit checked **2,549 archived files**, **160 sample rows**, **340 positive full-coverage perf runs**, and independently reconstructed the ELF payload hashes and text totals for all eighty timed compile outputs.
