# Constant checked multiplication after loop peeling

The actual default now uses **1.13119791 × LLVM MIR0** dynamic instructions over the unchanged thirteen workloads. This is **0.3553%** fewer instructions than `029378f` (PR13), with semver parse **2.8266%** and semver req **1.7445%** lower. The other eleven instruction counts are unchanged within counter variation. The objective remains incomplete: only 7/13 runtime instruction ratios, 1/4 compile instruction ratios and 0/4 crate text ratios meet 1.1.

The shared integer constant evaluator previously omitted `MulOverflow`. Layout loop peeling created a `MulOverflow(0,10)` in the first iteration; multiplication folded but its overflow flag and branch survived. Evaluation now uses the operand width and signedness, with a wider intermediate for signed and unsigned products up to 64 bits. Both operands must be constants. Dynamic and poison operands keep their original behavior. InstCombine, the splice worklist and SCCP share this evaluator. `KFRC_FOLD_MUL_OVERFLOW=0` is the independent old-path ablation.
