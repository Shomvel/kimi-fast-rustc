# 表示、存储与 ABI

本轮沿 Fable 第一性原理审查的 A3 推进。原问题是布局降低把完整值拆成每个变体的字段，再经栈槽重新编码，
随后机器层无法跨复制或不同宽度访问消掉这些内存操作。修复的边界是值的表示和归属，适用于所有类型的相同操作。

## 整体传递与字段观察

R/S 的值仍有 Rust 类型、变体和初始化契约。L 不因一个值需要按 ABI 传递就检查它的每个字段。
`lower_layout/transport.rs` 对只被完整返回、完整存储或按值调用消费的 ABI 值保留完整表示。
这些消费者对 enum、数组、普通聚合和 `MaybeUninit` 使用同一条路径。

参数在入口捕获私有字节快照，保留原固定读取位置，避免后续效果经别名改变参数值。
调用结果已有本次调用独占的存储，可以作为不可变的完整值继续传递。
把它传给另一次按值调用时仍建立该调用独占的实参，不能借用旧快照让被调者改写。
字段观察、判别值查询和循环 Phi 继续使用现有字段需求路径；本轮尚未统一这些表示。

## 按访问范围分配存储

`kfrc-cranelift/export/promote.rs` 收集私有存储的所有固定字节范围，包括显式 ABI lane 和完整复制范围。
重叠访问共用字节表示：将重叠范围的并集划为互不重叠的 1/2/4/8 字节整数 lane。
独立且相邻的字段可以保持独立 lane。

读取按小端顺序提取并拼合范围；写入只替换命中的位，其余位取旧值。
因此窄写、跨字边界访问、enum 变体的不同宽度字段、ABI word 传递遵守同一规则。
常量长度复制给整个范围分配 lane，包括未被字段访问命名的字节；复制先读取完整源范围，再写目的范围，
支持同一存储内前后重叠的 `memmove`。地址逃逸、变量偏移及无法证明独占的合并仍使用真实内存。

lane 是发布机器表示，不代表合法 Rust 整数，也不授予解引用权限。
未初始化和 padding 的搬运不能增加源语言的有效性要求；当前机器化过程可为未定义位选择零，
不得据此把未初始化的源 Rust 值视为有效。抽象字节的初始化和 provenance 语义仍由语义层与解释器负责。
本轮没有把新的 `Bytes` 类型或初始化分析强行加进 IR。

## 位置转发

间接返回的调用结果与本函数返回类型相同，并且该块调用之后直接返回同一完整表示时，
调用使用本函数的 sret 位置，不建立中间栈对象。返回也不再拷贝同一位置。
存在中间效果、字段重建、非零偏移或不同结果类型时保留原路径。

## 降低后的化简

字节范围提升把私有存取变成整数和 SSA 块参数；Cranelift 的同一个优化器随后处理这些运算，
而非为 enum、`MaybeUninit` 和某个热函数各增加一套机器规则。
Fable 的 A4（R/S/L 共用的节点契约、稀疏工作表、分区内存 SSA）仍是后续工作，不能以 Cranelift 中端冒充完成。

## 验证

最小图覆盖混合宽度和偏移、复制重叠、间接结果最终位置；真实 rustc runner 为
`crates/rustc_codegen_kfrc/tests/storage-representation/run.sh`，比较 LLVM、原 x86、Cranelift 内存和 Cranelift lane 四路。
它用 4096 组输入检查局部字节替换、跨 lane 复制、双向重叠、部分初始化 `MaybeUninit` 与 ABI 转发。
四库 13 项负载、完整语料、受支持的现有 E2E 套件以及同机性能对照负责验证真实程序。
