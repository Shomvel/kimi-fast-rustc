# L 图到 Cranelift IR 的映射

实现在 `crates/kfrc-cranelift/src/export.rs` 及其子模块。

## 值

L 级标量保持自己的整数宽度：`bool`、`u8` 是 `i8`，`char`、`u32` 是 `i32`，指针与地址是 `i64`。有无符号由操作体现
（扩展种类、比较谓词、除法种类），与图一致。没有位的值（`()`、`!`、函数项）没有 Cranelift 值。
聚合值在 L 级是其存储的地址（`LayoutValue`）。

## 控制

每个排程块对应一个 Cranelift 块。固定节点按链的顺序发射；纯节点在排程指定的块里、首次被需要时发射；
Region 的 Phi 是块参数，前驱 `Jump` 传入对应输入。

- `If`：条件是一串布尔取反时，每次取反交换一次两个后继；对比较取反得到互补谓词的比较。
- `Unreachable`：陷阱指令。以它结尾的块，以及后继全是冷块的块，标为冷块，布局在函数末尾。
- 每次调用之后另起一个 Cranelift 块：Cranelift 在每个使用常量的块里重新生成常量，这样调用两侧的常量各自生成，
  不占用跨调用的被调者保存寄存器。

## 算术

- 普通移位：Cranelift 对位数取模，与图的定义相同。
- `MulOverflow` 与同操作数的 `Mul`：一条带溢出标志的乘法同时给出积和溢出位，被支配的 `Mul` 复用它的积。
- 除法与取余是固定节点，按链的位置发射；常量除数由 Cranelift 的规则改写成乘法。
- 位计数、字节反转、位反转、漏斗移位、饱和加减：映射到 Cranelift 的对应指令；目标描述是 SSE2 基线，
  Cranelift 选择不依赖 POPCNT/LZCNT/TZCNT 的序列。

## 内存

- `Load`、`Store`：按值的宽度访问；地址是否对齐由位置决定，访问标志只声明“不会陷入”。
- `StackSlot`：没有成为 lane 的存储是 Cranelift 的显式栈槽；对齐高于 16 时在放大的栈槽里对地址取整。
- 小的常量长度 `memcpy`/`memmove`（至多 64 字节）：先读完所有块再写，块宽最大 16 字节；尾部按 8/4/2/1 需要多于一块时，改用一个与前一块重叠的同宽块。
- 经认证的 `bcmp`（至多 32 字节）：按块读取、异或、合并后比较一次。同名的用户函数没有读取契约，保持调用。

## 调用边界

图为每个参数与返回值记录 rustc 的 `PassMode`。导出器把它翻译成 System V 签名里的寄存器 lane，Cranelift 按顺序分配
整数与向量寄存器、其余进栈。lane 的选法与 rustc 自带的 Cranelift 后端（`rustc_codegen_cranelift` 的 `abi/pass_mode.rs`）一致。

| `PassMode` | lane |
|---|---|
| `Ignore` | 无 |
| `Direct`（标量） | 一个该宽度的整数；窄于 32 位时在签名上声明扩展 |
| `Direct`（1/2/4/8 字节聚合） | 一个该字节数的整数 |
| `Pair` | 两个字段各一个整数 |
| `Cast` | 每个整数 lane 一个 `i64`，可带一个 `i32` 填充 |
| `Vector { bytes: 16 }` | 一个 `i8x16` |
| `Indirect` | 一个指针；作为返回方式时是首个参数，并由被调函数返回 |

没有 `Return` 的函数（所有路径都发散）签名不带返回 lane。

## 符号与线程局部

符号地址是 RIP 相对的 `lea`，调用是 rel32，由链接器直接绑定或经 PLT 绑定。线程局部地址用通用动态序列，
链接可执行文件时由链接器放宽为 local-exec。
