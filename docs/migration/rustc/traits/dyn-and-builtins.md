# dyn 兼容性、vtable、auto trait 与 builtin/lang item trait

## dyn 兼容性（对象安全）

查询 [`dyn_compatibility_violations`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L48) 对 trait 及其所有 supertrait（`supertrait_def_ids`）求 [`dyn_compatibility_violations_for_trait`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L80)，结果为空即兼容。

- **trait 级：** `Self: Sized` 约束（`SizedSelf`）；supertrait/where 谓词以 `Self` 作为非 self 位置的参数（`SupertraitSelf`，如 `trait T: PartialEq<Self>`）；item bound 引用 `Self`；supertrait 含非 lifetime 的高阶绑定；supertrait 无条件 const。
- **关联项级**（[`..._for_assoc_item`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L308)）：带 `where Self: Sized`（[`generics_require_sized_self`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L283)）的项豁免；关联常量一律违规；GAT（有自身泛型参数的关联类型）违规；普通关联类型允许（须在 `dyn` 类型里指定）。
- **方法**（[`virtual_call_violations_for_method`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L362)）：没有 `self` 参数；参数或返回值中以非法方式引用 `Self`（`Self::Assoc` 投影允许）；返回 RPITIT / `async fn`；C 可变参数；有类型或常量泛型参数；接收者不可分派（[`receiver_is_dispatchable`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L587)，基于 `Unsize` + `DispatchFromDyn`；`self: Self` 特例允许）；where 子句引用 `Self`（只发 lint）。
- [`is_vtable_safe_method`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/dyn_compatibility.rs#L68)：方法不要求 `Self: Sized` 且没有方法级违规 → 进入 vtable。

求解器侧：`DynCompatible(trait)` 谓词直接查询（[`compute_dyn_compatible_goal`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/mod.rs#L134)）；principal 不兼容时不收集 object 候选，也不允许 unsize 到该 `dyn`。

## `dyn Trait` 的候选

[`assemble_object_bound_candidates`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/mod.rs#L789)：只对 `implement_via_object` 的 trait；auto trait 与 projection 存在谓词作为 `BuiltinImplSource::Misc` 候选；principal 经 `supertraits` 展开，第 `i` 个作为 `Object(i)` 候选。匹配后还要证明该 trait 的 supertrait 与相关谓词（[`predicates_for_object_candidate`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L845)）。object 候选与用户 blanket impl 同时适用时优先 object（`dyn Any` 的 `type_id` 走 vtable，`tests/ui/traits/dyn-any-prefer-vtable.rs`）。

**Unsize 到 dyn**（[`consider_builtin_unsize_to_dyn_candidate`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/trait_goals.rs#L927)）：目标 principal 必须 dyn 兼容；源类型要满足目标 `dyn` 的全部存在谓词、`Sized`，并且 outlive `dyn` 的 region。另有 `dyn A → dyn B` 的 upcasting（[`consider_builtin_upcast_to_principal`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/trait_goals.rs#L968)）、数组到切片、结构体尾部 unsize。

## vtable 布局

[`prepare_vtable_segments_inner`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/vtable.rs#L36)：先放 `MetadataDSA` 段（[`VtblEntry`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/ty/vtable.rs#L13)：`MetadataDropInPlace`、`MetadataSize`、`MetadataAlign`）；再对 supertrait 图做 DFS：第一个直接 supertrait 的整张 vtable 作为前缀，其余 supertrait 依次放“自己的方法 + `TraitVPtr`”，最后放本 trait 的方法；已访问的 trait 跳过（菱形只出现一次）；没有方法且 supertrait 也没有方法的 trait 不放 vptr。

[`vtable_entries`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/vtable.rs#L227)：每段的方法 = 定义顺序中 `is_vtable_safe_method` 的方法（[L201](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/vtable.rs#L201)）；对具体 trait ref 的方法谓词若 `impossible_predicates`（新求解器，[L275](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/traits/vtable.rs#L275)）则为 `Vacant`，否则 `Instance::expect_resolve_for_vtable`。T25 需要：supertrait 顺序（`explicit_super_predicates_of`）、方法定义顺序、dyn 兼容性、实例解析，以及 drop glue 实例。

## auto trait

[`consider_auto_trait_candidate`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/trait_goals.rs#L197)：只对正极性；[`disqualify_auto_trait_candidate_due_to_possible_impl`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/trait_goals.rs#L1158)：对刚性类型，只要有**任何**用户 impl（含负 impl）可能适用，就取消结构化的 auto impl；int/float 变量强制歧义；`dyn`、参数、placeholder、projection 没有 auto impl；opaque 可泄漏 auto trait（若 item bound 已给出则不泄漏，避免查询环）。结构化规则（[`instantiate_constituent_tys_for_auto_trait`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L22)）：ADT → 全部字段类型；`PhantomData<T>` → `T`；`str` → `[u8]`；指针/引用/数组/切片 → 元素；元组 → 各元素；闭包 → upvar 元组；`unsafe trait` 遇到 unsafe 字段时不给 auto impl。auto trait 是余归纳的（`c07` 递归链表 `Send` 通过）。

## `Sized` / `Copy` / `Clone` / `Fn*` / `Drop`

- **`Sized`/`MetaSized`**（[`instantiate_constituent_tys_for_sizedness_trait`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L108)）：基本类型、指针、引用、数组、闭包、`!` 无条件成立；`str`/`[T]`/`dyn` 只满足 `MetaSized`；extern type 都不满足；元组看最后一个元素；ADT 看 `sizedness_constraint`（最深的尾字段，可为空）；参数/alias/placeholder 没有 builtin（只能靠 where-bound）。候选来源为 `Trivial`，合并时最优先。
- **`Copy`/`Clone`**（[`..._copy_clone_trait`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L187)）：builtin 只覆盖 FnDef、FnPtr、元组、闭包（看 upvar）、可选的 coroutine；**基本类型、`&T`、原始指针、`!`、数组的实现来自 core 中的 impl**（[注释 L199](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L199)；core 的 [`marker_impls! { Copy for usize, ... }`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/library/core/src/marker.rs#L481)、`impl Copy for !`、`impl<T: PointeeSized> Copy for &T`，行号按 Homebrew 1.94.1 rust-src 核对），ADT 只能靠 impl/derive；`&mut T` 永不 Copy。`Copy` impl 的字段检查在 [`visit_implementation_of_copy`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_hir_analysis/src/coherence/builtin.rs#L89)。
- **`Fn`/`FnMut`/`FnOnce`**（[`consider_builtin_fn_trait_candidates`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/trait_goals.rs#L353)、[`extract_tupled_inputs_and_output_from_callable`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_next_trait_solver/src/solve/assembly/structural_traits.rs#L269)）：FnDef（safe、Rust ABI、非 C 可变参数、无 target feature）、同样条件的 fn 指针、闭包（闭包 kind 必须 extends goal kind；kind 未定时只有 `FnOnce` 成立，其余歧义）；参数打包成元组；额外要求输出 `Sized`；`FnOnce::Output` 投影由同一路径给出。
- **`Drop`**：求解器没有 `Drop` builtin；`T: Drop` 只看用户 impl。`Drop` impl 只能写给本地 ADT（[`visit_implementation_of_drop`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_hir_analysis/src/coherence/builtin.rs#L71)），且必须与 ADT 定义的参数和谓词完全对应（[`check_drop_impl`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_hir_analysis/src/check/always_applicable.rs#L37)）。需不需要析构由 `needs_drop` / drop glue 决定（T22/T25），不经 trait 求解；const 上下文用 builtin 的 `Destruct`。

## Codegen 选择

单态化要知道“具体用哪个 impl”。默认 [`codegen_select_candidate`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_traits/src/codegen.rs#L24) 用旧求解器 `select` 得到 `ImplSource`，再用 fulfillment 解出 impl 参数。`globally` 模式下改为 [`select_in_new_trait_solver`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/solve/select.rs#L20)：在 proof tree 上取根 goal 的成功候选，只在 `Certainty::Yes` 时按 [`candidate_should_be_dropped_in_favor_of`](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_trait_selection/src/solve/select.rs#L92) winnow。

**对 kfrc 的含义：** 自有求解器在 `TypingMode::PostAnalysis` 下的成功结果应同时给出 `Selection { source: CandidateSource, impl_args }`（不必构造完整 proof tree），供 T25 的 InstanceKey、vtable 和 drop glue 使用；`Copy` 等 lang item trait 在没有 core 的 M1 用例中需要一个带 `#[lang]` impl 的 mini core，否则 `i32: Copy` 不成立。
