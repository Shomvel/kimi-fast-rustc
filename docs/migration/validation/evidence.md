# 证据包与执行环境

## 每次验收保存

- `manifest`：命令、配置、输入摘要
- baseline / candidate 编译器与对象哈希
- host/target 与实际资源
- 产物来源（每个对象由谁生成）
- 原始日志、差分结果、性能样本
- 通过 / 失败 / 跳过的具体集合；跳过项写明能力缺口

路径用仓库相对位置或公开可访问的持久链接，不依赖个人本地绝对路径。凭据不进入日志或产物。

## 每个工作包 PR 附带

固定输入与源 commit、实现来源及许可、修改的表示契约、支持/拒绝范围、真实执行命令与原始结果、图/对象指纹、剩余风险、回退方法。

## 执行环境

- 并行编译、profile、正式测量优先在配置可核实的隔离环境中进行，记录模板/镜像身份和实际资源。
- 每个完整配置一个独立环境；同一配置的基线与候选在同一环境中串行对照。
- profile 与正式计时分开。
- 不混合不同宿主机的绝对耗时。

具体主机、模板和凭据位置遵循仓库执行环境的约定，不写入本设计文档。
