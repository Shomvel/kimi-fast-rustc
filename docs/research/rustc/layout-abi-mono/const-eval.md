## 解释器结构

- `InterpCx{machine, tcx, typing_env, memory, recursion_limit}`（[eval_context.rs#L29](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/eval_context.rs#L29)）；`Machine` trait（[machine.rs#L99](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/machine.rs#L99)）提供 provenance 类型、内存/调用/intrinsic/对齐/校验等钩子，CTFE 与 Miri 是两个实现。
- 栈：`Frame` + `LocalState`（[stack.rs#L60](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/stack.rs#L60)、[#L140](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/stack.rs#L140)）。局部变量是 `LocalValue::{Dead, Live(Operand)}`，只存立即数且不取地址时不分配内存（[stack.rs#L161](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/stack.rs#L161)、`Place::Local`，[place.rs#L183](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/place.rs#L183)）。
- 值：`Scalar = Int(ScalarInt{bits,size}) | Ptr(Pointer, size)`（[value.rs#L24](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/interpret/value.rs#L24)）；`Immediate = Scalar | ScalarPair | Uninit`（[operand.rs#L34](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/operand.rs#L34)）；`OpTy = (Immediate | MemPlace) + 布局`；`MPlaceTy = 指针 + MemPlaceMeta(None|Meta) + 布局`（[place.rs#L24](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/place.rs#L24)）。**Immediate 的形状跟随 `backend_repr`**（Scalar/ScalarPair），所以解释器必须用和 codegen 相同的布局。
- 内存：`Memory{alloc_map: AllocId→(MemoryKind, Allocation), extra_fn_ptr_map, dead_alloc_map}`（[memory.rs#L113](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/memory.rs#L113)）。`Allocation{bytes, provenance: ProvenanceMap, init_mask, align, mutability}`（[allocation.rs#L94](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/interpret/allocation.rs#L94)）：字节、逐字节初始化位图、“哪些偏移存着指针”的表分开存。
- 指针：`Pointer{provenance, offset}`（[pointer.rs#L226](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/interpret/pointer.rs#L226)），CTFE 的 provenance 是 `CtfeProvenance` = `AllocId` + immutable + shared_ref 两个标志位（[#L91](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/interpret/pointer.rs#L91)）。**没有绝对地址**：offset 相对分配起点（`OFFSET_IS_ADDR = false`）。
- 全局分配：`GlobalAlloc = Function{instance} | VTable(ty, dyn) | Static(def) | Memory(ConstAllocation) | TypeId{ty}`（[mod.rs#L260](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/interpret/mod.rs#L260)）。`AllocId` 是全局编号；函数指针、vtable、static 都只是带特殊 `GlobalAlloc` 的 `AllocId`。

## CTFE machine 的限制（[const_eval/machine.rs](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs)）

- 只能调用 `const fn`（及 const trait 内的方法），否则 “calling non-const function”（[#L420](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L420)）；部分函数被 `hook_special_const_fn` 替换（panic 等）。
- 指针：int→ptr 得到无 provenance 指针，解引用失败（[interpret/machine.rs#L721](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/machine.rs#L721)）；ptr→int（expose）报错（[#L727](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L727)）；指针算术/比较的 `binary_ptr_op` 报 unsupported（[#L655](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L655)），`ptr_guaranteed_cmp` 返回 0/1/2（2=不知道，[#L274](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L274)）。
- 全局内存：写任何全局分配都报错；`const` 不能读可变全局（`static mut`/内部可变 static），static 初始化可以（[#L762](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L762)）；读正在求值的 static 自己报 `RecursiveStatic`，读别的 static 会触发其求值以检测环（[#L848](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L848)）；通过不可变指针写报错。
- 堆：`const_allocate` 得到 `MemoryKind::Heap`，最终值里出现必须先 `const_make_global`。
- 资源：每个 terminator 计数，2,000,000 时触发 deny-by-default lint `long_running_const_eval`，4,000,000 之后每 2 的幂打印进度（[#L33](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L33)、[#L664](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L664)）；栈深度受 `recursion_limit`。
- 溢出检查始终开启（`ignore_optional_overflow_checks = false`，[interpret/machine.rs#L643](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/machine.rs#L643)；`runtime_checks` 恒 true，[#L646](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L646)）：结果不随 `-C overflow-checks` 变化。不支持 unwinding。
- 对齐：解引用未对齐指针是硬错误。逐次 typed copy 不做有效性检查（`enforce_validity` 只在 `-Zextra-const-ub-checks` 或类型 uninhabited 时为真，[#L406](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/machine.rs#L406)），只在最后验一次。

## 驻留与有效性

- `intern_const_alloc_recursive(InternKind)`（[intern.rs#L203](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/intern.rs#L203)）：从返回值出发把所有可达的本地分配变成全局分配；`Static(Mut)` 外一般设为不可变。错误：悬垂指针、最终值含可变引用、堆分配未 make global、部分指针（指针字节被拆开）。
- `const_validate_mplace`（[eval_queries.rs#L422](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/eval_queries.rs#L422)）用 `RefTracking` 递归验证引用指向的内存，模式 `CtfeValidationMode::{Static, Promoted, Const}`（[validity.rs#L141](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/validity.rs#L141)）。`ValidityVisitor` 检查：bool 0/1、char 合法、整数/浮点已初始化且不带 provenance、引用非空/对齐/可解引用、fn 指针非空且指向函数、`!` 不可能出现、enum tag 可解码、标量 `valid_range`、宽指针元数据（slice 长度、vtable 类型）、不可变内存里的 `UnsafeCell`（顶层 const 例外）（[#L675](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/validity.rs#L675)、[#L802](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/interpret/validity.rs#L802)）。
- `op_to_const`（[eval_queries.rs#L213](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/eval_queries.rs#L213)）：ZST → `ZeroSized`；`Scalar(Initialized)` 布局 → `ConstValue::Scalar`；slice 引用 → `Slice{alloc_id, meta}`；其余 → `Indirect{alloc_id, offset}`（[consts.rs#L33](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_middle/src/mir/consts.rs#L33)）。

## promoted 常量

`PromoteTemps`（[promote_consts.rs](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_mir_transform/src/promote_consts.rs)）把 `&<常量表达式>` 的临时值提到独立 MIR body，结果 `'static`。条件：临时值只赋值一次、无内部可变性、无需 drop；不能有 `ThreadLocalRef`、ptr→int；整数除法/取余只在除数是非零常量（有符号还要排除 `MIN / -1`）时才提升（[#L482](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_mir_transform/src/promote_consts.rs#L482)）；函数调用只提升 `#[rustc_promotable]` 的，const/static 初始化器里出于兼容放宽（[#L637](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_mir_transform/src/promote_consts.rs#L637)）。求值用 `GlobalId{promoted: Some(i)}`、`InternKind::Promoted`。

## const 泛型与值树

`ValTreeKind = Leaf(ScalarInt) | Branch([ValTree])`（[const_kind.rs#L149](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_type_ir/src/const_kind.rs#L149)）。`const_to_valtree_inner`（[valtrees.rs#L79](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/valtrees.rs#L79)）：整数/bool/char/浮点 → Leaf；tuple/数组/struct → Branch；enum → Branch[变体下标, 字段…]；`&T` 按指向的值；裸指针只接受“伪装的整数”；fn 指针、union、`dyn`、闭包拒绝；节点数有上限。`valtree_to_const_value`（[#L264](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_const_eval/src/const_eval/valtrees.rs#L264)）反向重建。类型系统按值树做相等比较，所以 `Foo<{1+1}>` 与 `Foo<2>` 是同一类型。

## 常量进入代码生成

- `OperandRef::from_const`（[operand.rs#L153](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_codegen_ssa/src/mir/operand.rs#L153)）：`Scalar` → 立即数；`ZeroSized`；`Slice` → (分配地址, len)；`Indirect` → 若布局是全初始化的 Scalar/ScalarPair 就从分配里读出立即数，否则作为只读全局的内存操作数。
- `scalar_to_backend`（[codegen_llvm common.rs#L263](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_codegen_llvm/src/common.rs#L263)）把 `Scalar::Ptr` 的 provenance 映射为符号：`Memory` → 按内容哈希命名的私有全局（空分配直接用 `align + offset` 作为整数地址），`Function` → 函数地址，`VTable` → vtable 全局，`Static` → static 符号，`TypeId` → offset 里的哈希值。
- `const_alloc_to_llvm`（[consts.rs#L29](https://github.com/rust-lang/rust/blob/e408947bfd200af42db322daf0fadfe7e26d3bd1/compiler/rustc_codegen_llvm/src/consts.rs#L29)）：按 provenance 表把字节切成“数据块 + 指针重定位”，未初始化字节输出 undef（块数过多时整体按初始化处理）。

## tricky 边界

- 同一常量在不同 CGU 被多次发射；地址不保证唯一（`unnamed_addr`），static 地址才唯一。
- 部分指针（指针的几个字节被拷走）在最终值里是错误；运行时 transmute 才可能出现。
- `ConstValue::Indirect` 可以指向更大分配的中间（`offset`）。
- 常量求值失败在单态化时才报（泛型常量），必须通过 mentioned items 保证与优化级别无关，见 [mono-collector.md](mono-collector.md)。
